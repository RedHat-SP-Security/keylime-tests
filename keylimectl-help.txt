================================================================
$ keylimectl --help
================================================================
keylimectl provides an intuitive interface for managing Keylime agents, policies, and attestation. It replaces keylime_tenant with improved usability while maintaining full API compatibility.

Usage: keylimectl [OPTIONS] [COMMAND]

Commands:
  agent          Manage agents
  policy         Manage runtime policies
  measured-boot  Manage measured boot policies
  info           Show diagnostic information
  verify         Verify attestation evidence against a verifier
  configure      Create or update a configuration file
  help           Print this message or the help of the given subcommand(s)

Options:
  -c, --config <FILE>
          Configuration file path

      --verifier-ip <IP>
          Verifier IP address [default: 127.0.0.1]

      --verifier-port <PORT>
          Verifier port [default: 8881]

      --registrar-ip <IP>
          Registrar IP address [default: 127.0.0.1]

      --registrar-port <PORT>
          Registrar port [default: 8891]

      --timeout <SECONDS>
          Request timeout in seconds [default: 60]

  -v, --verbose...
          Enable verbose logging

  -q, --quiet
          Suppress all output except JSON results

      --format <FORMAT>
          Output format

          Possible values:
          - json:  JSON output (default)
          - table: Human-readable table format
          - yaml:  YAML output
          
          [default: json]

      --color <COLOR>
          Color output mode

          Possible values:
          - auto:   Auto-detect based on terminal
          - always: Always use colors
          - never:  Never use colors
          
          [default: auto]

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

CONFIGURATION SOURCES (highest to lowest priority):
  1. Command-line arguments (--verifier-ip, --timeout, etc.)
  2. Environment variables (KEYLIME_VERIFIER__IP, KEYLIME_CLIENT__TIMEOUT, etc.)
  3. Configuration files (keylimectl.toml, ~/.config/keylimectl/config.toml, etc.)
  4. Built-in defaults

Run `keylimectl configure` to create a configuration file interactively.

$ keylimectl agent add --help
================================================================
Add an agent to the verifier

Usage: keylimectl agent add [OPTIONS] <AGENT_ID>

Arguments:
  <AGENT_ID>  Agent identifier (can be any string, not necessarily a UUID)

Options:
      --ip <IP>                        Agent IP address (if not using push model)
      --port <PORT>                    Agent port (if not using push model)
      --verifier-ip <IP>               Verifier IP for the agent to connect to
      --runtime-policy <POLICY>        Runtime policy to apply
      --runtime-policy-name <NAME>     Name for the runtime policy in the verifier database
      --runtime-policy-sig-key <FILE>  Public key file to verify the runtime policy DSSE signature
      --mb-policy <POLICY>             Measured boot policy to apply
      --payload <FILE>                 Payload file to deliver securely
      --cert-dir <DIR>                 Certificate directory for secure delivery
      --verify                         Verify cryptographic key derivation
      --push-model                     Use push model (agent connects to verifier)
      --pull-model                     Force pull model (legacy API 2.x behavior, overrides auto-detection)
      --tpm-policy <POLICY>            TPM policy in JSON format
      --wait-for-attestation           Wait for first attestation to complete after enrollment
      --attestation-timeout <SECONDS>  Timeout in seconds for --wait-for-attestation (default: 60) [default: 60]
  -h, --help                           Print help

$ keylimectl policy generate runtime --help
================================================================
Generate a runtime policy from IMA logs, allowlists, or filesystem

Usage: keylimectl policy generate runtime [OPTIONS]

Options:
  -I, --interactive
          Run the interactive wizard to guide policy creation
  -m, --ima-measurement-list [<FILE>]
          IMA measurement list path. If -m is given without a value, uses the default: /sys/kernel/security/ima/ascii_runtime_measurements
  -a, --allowlist <FILE>
          Plain-text allowlist file
      --rootfs <PATH>
          Root filesystem path to scan
      --skip-path <PATH>
          Paths to skip during filesystem scan (repeatable)
  -B, --base-policy <FILE>
          Base policy to merge into
  -e, --excludelist <FILE>
          IMA exclude list file
  -o, --output <FILE>
          Output file (stdout if omitted)
  -k, --keyrings
          Include keyrings entries
      --ima-buf
          Include ima-buf entries
  -i, --ignored-keyrings <KEYRING>
          Keyrings to ignore (repeatable)
  -A, --add-ima-signature-verification-key <FILE>
          Add IMA signature verification key (repeatable)
      --hash-alg <ALG>
          Hash algorithm (auto-detected if omitted)
      --ramdisk-dir <DIR>
          Directory containing initramfs files (e.g., /boot)
      --local-rpm-repo <DIR>
          Local RPM repository directory
      --remote-rpm-repo <URL>
          Remote RPM repository URL
      --gpg-key <FILE>
          GPG public key file for verifying RPM repository metadata signatures
  -h, --help
          Print help

      --registrar-port <PORT>
